# Calculadora de Precificacao - Impressao 3D no Japao

Ferramenta gratuita, sem cadastro. Calcula custo real, preco minimo e preco sugerido
de uma peca impressa em 3D, em iene: material, depreciacao da maquina, energia,
mao de obra, taxa de falha, embalagem, comissao e imposto.

Pagina unica, sem dependencia externa - funciona offline.

## Teste

```
node test_calculadora.mjs
```

Confere contra o exemplo do livro (chega a 1.190 ienes).
